# SMS-Fraud-Detection

AI-Powered Fraud Detection & Financial Safety Platform

About
A machine learning project designed to help users identify potentially fraudulent SMS messages and suspicious websites.

Modules
1. SMS Scam Detection
2. Fake Website / URL Detection

Technology Stack
- Frontend: React.js
- Backend: FastAPI
- Machine Learning: Python, Pandas, Scikit-learn
- Database: PostgreSQL
- Version Control: Git and GitHub

Current Progress
- Project repository created
- Initial folder structure created
- SMS dataset inspection
- Data preprocessing
- Model training and evaluation
- FastAPI integration
- React frontend integration
- PostgreSQL integration

Disclaimer
Predictions are estimates, not guarantees that a message or website is safe or fraudulent.
